# GWSS:3005 Practicum Curriculum Guide

A student-facing curriculum portal for the Gender, Women's, and Sexuality Studies Practicum at the University of Iowa.

## What's Included

- **Syllabus & expectations** (Start Here)
- **Broad community partner definitions** (babysitting to advocacy)
- **6 guided phases** from research question to final proposal
- **Critical theory reflection prompts** (Document 1)
- **Community engagement reflection prompts** (Document 2)
- **Final project proposal template**
- **Suggested readings** organized by phase
- **Service hour tracker** (runs in browser, exports to CSV)

## Files

- `index.html` - Main site
- `style.css` - Styles
- `script.js` - Interactivity (tracker, accordion, mobile nav)
- `README.md` - This file

## Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g., `gwss-practicum-guide`)
2. Upload these files to the main branch
3. Go to **Settings > Pages**
4. Under "Build and deployment," select **Deploy from a branch**
5. Choose the `main` branch and `/ (root)` folder
6. Click **Save**
7. Your site will be live at `https://yourusername.github.io/gwss-practicum-guide/`

## Local Use

Simply open `index.html` in any web browser. No server required.

## Notes

- Service hour data is stored in your browser's localStorage. Screenshot or export before clearing your cache.
- This is a curriculum guide. Student submissions happen through ICON.
